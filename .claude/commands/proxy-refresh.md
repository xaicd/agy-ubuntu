# 代理网络与宿主机直连刷新工作流 (Proxy Refresh & Bypass)

当你需要排查或修复沙箱/容器网络（如访问 Google/Gemini 遇到地区限制、或访问宿主机/开发机超时）时，调用此命令。

权威规范详见：`.agents/skills/proxy-network-workflow/SKILL.md`

## 核心操作命令：
直接执行工作区安全持久化刷新脚本（纯 API 热重载，零进程重启，零断网风险）：
```bash
bash scripts/refresh-proxy.sh $ARGUMENTS
```

## 执行守则：
1. **零重启防死原则**：严禁通过 `pkill mihomo` 杀进程重启，必须通过 `127.0.0.1:9090` API 实行热重载，防止 TUN（`clash0`）网卡与 DNS 崩溃；
2. **合规节点锁定**：出海代理池仅允许 **日本、美国、智利、新加坡、台湾**，硬排除 **香港、澳门**，确保 Google Gemini 与 Claude API 永不触发区域限制；
3. **宿主机自适应直连**：自动嗅探默认网关（宿主机）并直连放行 `100.64.0.0/10`（Tailscale）、`192.144.0.0/16`、`172.16.0.0/12` 等私网段，确保开发机与测试机访问畅通；
4. **验证闭环**：执行完成后必须回显宿主机网关连通性（HTTP 200）与 Google 连通性（HTTP 204）。
